# GSE338230: bulk RNA-seq gene counts

Bulk RNA-seq of mouse hippocampus, 20 libraries: poly(A)-selected, strand-specific (NEBNext Ultra II
Directional), paired-end 150 bp on an Illumina NovaSeq X. Used by `notebooks/bulk_rnaseq_analysis.ipynb`.

## File

`GSE338230_counts_gene_all.csv`, a supplementary file of the GEO series.

| Content | |
|---|---|
| Rows | 35,532 genes; first column `gene_id`, Ensembl gene IDs (GRCm39) without version |
| Columns | One per library |
| Values | Salmon estimated read counts summed per gene (non-integer; rounded before DESeq2) |

## Processing

1. Reads trimmed with fastp (automatic adapter detection, poly-G and poly-X trimming, quality 15, minimum
   length 15).
2. Salmon 1.10.0 against the Ensembl mouse cDNA, GRCm39 release 110 (selective alignment, `-l A`,
   `--gcBias`).
3. Estimated reads summed per gene with the transcript-to-gene map of the Ensembl GRCm39 release 109 GTF.

Code for steps 2 and 3: `notebooks/salmon_quantification.ipynb`.

## Sample sheet

`bulk_rnaseq_analysis` needs a CSV with one row per library, with the library name (the column name in
the count matrix) and its condition. Sample annotations are in the GEO series.
